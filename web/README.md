# web

Interface do Rumo (Next.js, App Router, TypeScript).

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # vitest + Testing Library
```

A página inicial lê `GET {API_URL}/health` no servidor. `API_URL` padrão: `http://localhost:8000`.
Tokens de design (cores, raios, escala tipográfica, claro/escuro) ficam em `app/globals.css`.
